# PhoneTracker

Open `PhoneTracker.xcodeproj` in Xcode.

1. Select the PhoneTracker target, open Signing & Capabilities, and set Team to your Apple ID.
2. Plug in the iPhone and choose it as the run destination.
3. Press Run.

On the phone, turn on Developer Mode if iOS asks, then trust the certificate under Settings → General → VPN & Device Management. A free Apple ID install lasts 7 days.
